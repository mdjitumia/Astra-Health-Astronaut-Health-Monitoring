# 🚀 ASTRAHEALTH
### AI-Powered Astronaut Health Monitoring & Decision Support System

> **Protect the Astronaut.**

ASTRAHEALTH is an AI-powered health intelligence platform designed to support astronaut health monitoring during long-duration space missions.

Instead of analyzing isolated health measurements, AstraHealth combines physiological and behavioral indicators, personalized health baselines, trend analysis, AI/ML-based risk assessment, explainable insights, and decision-support recommendations.

**Core Idea:**

**Don't just monitor health. Understand the change, explain the risk, and support the next action.**

## 🛰️ NASA Space Apps Challenge 2026

Developed for the **NASA Space Apps Challenge 2026**.

**Challenge:** Create Health Monitoring Software for Astronauts on Space Missions.

Long-duration space missions expose astronauts to radiation, isolation and confinement, altered gravity, and other challenging environmental conditions.

ASTRAHEALTH addresses these challenges through personalized health monitoring, longitudinal trend analysis, AI-assisted risk assessment, early warnings, and decision support.

---

## 🎯 The Problem

Important health changes during a long-duration space mission may develop gradually.

A slightly higher heart rate, reduced sleep, lower HRV, or increased stress may not be significant individually. However, when multiple health indicators deviate from an astronaut's normal pattern and persist over time, their combined trends may require attention.

The key question is:

> **"Is this change unusual for this astronaut?"**

Traditional monitoring approaches may focus on individual measurements. AstraHealth aims to provide a more comprehensive understanding of health changes through personalized monitoring and multi-parameter analysis.

---

## 💡 Our Solution

ASTRAHEALTH creates a personalized health-intelligence layer that helps monitor, analyze, and understand astronaut health conditions.

**Collect → Compare → Detect → Explain → Act → Re-monitor**

1. Collect health and behavioral indicators.
2. Establish an individual health baseline.
3. Compare new measurements against personal baselines.
4. Detect abnormal trends and patterns.
5. Estimate potential health risks.
6. Explain the contributing risk factors.
7. Provide decision-support recommendations.
8. Re-monitor health conditions after intervention.

---

## ⭐ Key Features & Capabilities

- ❤️ **Multi-Parameter Health Monitoring** — Heart rate, HRV, SpO₂, respiration, sleep, stress, activity, and recovery indicators.
- 🧬 **Personalized Health Baseline** — Evaluates changes against an astronaut's individual health patterns.
- 📈 **Longitudinal Trend Analysis** — Identifies persistent health changes over time.
- 🤖 **AI/ML Risk Analysis** — Supports multi-signal health-risk estimation using trained machine learning capabilities.
- 🔍 **Explainable AI** — Highlights contributing factors behind potential health risks.
- 🚨 **Early Warning System** — Identifies deviations and potential risk patterns.
- 🧠 **ASTRA AI Health Copilot** — Provides natural-language explanations and health-related insights.
- 🏃 **Countermeasure Decision Support** — Supports recovery, exercise, sleep, workload, and monitoring recommendations.
- 🌌 **Deep-Space Operation Mode** — Designed around local analysis and mission-control information needs.
- ⚡ **Adaptive Monitoring** — Supports increased monitoring when an astronaut's health condition changes.
- ☢️ **Radiation Monitoring & Protection** — Provides radiation-related monitoring information, exposure context, alerts, and protection guidance.

## 🖥️ Platform Modules

ASTRAHEALTH is organized into seven major modules.

### 1. Mission & Crew Dashboard

Provides a centralized mission overview with:

- Mission status and overview.
- Crew health overview.
- Individual astronaut health status.
- Key physiological indicators.
- Mission alerts and important updates.
- Crew selection and monitoring.

### 2. Personal Health Monitoring

Focuses on individual astronaut health conditions.

Key capabilities:

- Heart rate monitoring.
- Heart rate variability (HRV).
- Oxygen saturation (SpO₂).
- Respiratory rate.
- Sleep and recovery indicators.
- Personal baseline comparison.
- Health trends and deviation detection.

### 3. AI Risk Assessment

Provides AI/ML-assisted health-risk analysis.

Key capabilities:

- Health-risk assessment.
- Risk score and severity classification.
- Contributing risk-factor analysis.
- Health trend evaluation.
- Explainable risk insights.
- Decision-support recommendations.

### 4. Countermeasure & Recovery

Supports astronaut health and recovery management.

Key capabilities:

- Exercise recommendations.
- Sleep monitoring and guidance.
- Hydration monitoring.
- Workload review.
- Recovery tracking.
- Countermeasure recommendations.

### 5. Deep Space Mode

Designed for mission scenarios where communication with Earth may be delayed or limited.

Key concepts:

- Local health information access.
- Mission-oriented monitoring.
- Priority health information.
- Deep-space communication awareness.
- Onboard decision-support concept.

### 6. ASTRA AI Copilot

An AI-powered assistant that allows users to interact with astronaut health information through natural language.

Key capabilities:

- Health-related question answering.
- Risk explanation.
- Crew health information.
- Radiation-related research context.
- Countermeasure guidance.
- NASA research insights.

The application integrates the Google Gemini API for AI-powered interaction.

### 7. Radiation Monitoring & Protection

Focuses on radiation-related monitoring and astronaut protection.

Key capabilities:

- Radiation exposure information.
- Radiation monitoring dashboard.
- Exposure trends.
- Radiation alerts and warnings.
- NASA radiation research integration.
- Radiation protection and mission decision support.

# 🚀 Installation & Deployment Guide

Follow these instructions to clone, install, configure, run, and deploy your own AstraHealth instance.

## 1. Prerequisites

Make sure you have installed:

- Git
- Node.js 20.9 or later
- Bun (recommended)
- A Google Gemini API key

## 2. Clone the Repository

Open your terminal or PowerShell and run:

```bash
git clone https://github.com/mdjitumia/Astra-Health-Astronaut-Health-Monitoring.git
```

Navigate to the project directory:

```bash
cd Astra-Health-Astronaut-Health-Monitoring
```

## 3. Install Dependencies

Using Bun:

```bash
bun install
```

Alternatively, using npm:

```bash
npm install
```

## 4. Configure Environment Variables

Create a `.env` file in the root project directory.

Add your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Get your API key from:

https://aistudio.google.com/apikey

**Important:** Never upload your real API keys or secret credentials to GitHub.

## 5. Run the Application Locally

Using Bun:

```bash
bun run dev
```

Or using npm:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

You should now be able to access the AstraHealth application locally.

## 6. Build the Application

Using Bun:

```bash
bun run build
```

Or using npm:

```bash
npm run build
```

This command builds the application for production according to the project's build configuration.

## ☁️ Deploy on Vercel

You can deploy your own AstraHealth instance directly from GitHub using Vercel.

### Step 1: Fork or Push the Repository

You can fork the AstraHealth repository to your GitHub account or push your own copy of the source code.

Repository:

https://github.com/mdjitumia/Astra-Health-Astronaut-Health-Monitoring

### Step 2: Open Vercel

Visit:

https://vercel.com/

Sign in using your GitHub account.

### Step 3: Import the GitHub Repository

1. Click **Add New**.
2. Select **Project**.
3. Choose **Import Git Repository**.
4. Select your AstraHealth repository.
5. Click **Import**.

### Step 4: Configure Project Settings

Vercel should automatically detect the Next.js framework.

Use the following settings:

| Setting | Value |
|---|---|
| Framework Preset | Next.js |
| Root Directory | `./` |
| Install Command | `bun install` or automatic detection |
| Build Command | `npx next build` |
| Output Directory | Leave the Vercel default |

The build command above lets Vercel handle the Next.js production output.

### Step 5: Add Environment Variables

Open the **Environment Variables** section.

Add:

| Name | Value |
|---|---|
| `GEMINI_API_KEY` | Your Google Gemini API key |

Make sure the variable is available in the deployment environment you intend to use.

### Step 6: Deploy

1. Review your project settings.
2. Click **Deploy**.
3. Wait for the build process to finish.
4. Vercel will generate a live deployment URL.

### Step 7: Verify Your Deployment

After deployment:

- Open your Vercel URL.
- Check the mission dashboard.
- Navigate through the seven modules.
- Test the ASTRA AI Copilot.
- Check browser and Vercel logs if any errors occur.

**Congratulations! Your AstraHealth application is now deployed.**
